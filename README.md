# WLAN Pi Wireless Engineering Toolkit

Version: 1.0.0

A modular wireless engineering toolkit for WLAN Pi hardware.

## Architecture

- Client Profiling
- RF Survey
- Packet Capture
- Reports
- Export
- Deployment

## Design

The Mac is the source of truth.
The WLAN Pi is the runtime/deployment target.

## Current Capture Integration

WLAN Pi Go / Oscium remote capture integration remains vendor-dependent.
